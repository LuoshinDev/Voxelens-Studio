# Contributing / 参与贡献

欢迎提交 Issue 或 Pull Request。构建方法见 [Building](docs/BUILDING.md)，模块职责见 [Architecture](docs/ARCHITECTURE.md)。

- 问题反馈请附版本、复现步骤、预期与实际结果；分享截图和日志前移除个人信息。
- 一个 PR 聚焦一个问题，描述行为变化及实际检查结果。
- 界面文字同时更新中英文语言文件，并支持即时切换。
- 地图写入改动应说明取消、提交与失败恢复行为。
- 不提交 Minecraft JAR、私人地图、凭据或个人设置；新增素材注明来源和许可证。

原创贡献采用 [MIT](LICENSE)，第三方内容保留原许可。

## English

Issues and pull requests are welcome. See the build and architecture links above. Include clear reproduction steps for bugs; keep each PR focused and describe the behavior and checks performed. Update both interface languages. Explain cancellation and recovery when changing world writes. Do not submit private worlds, game archives, credentials or personal settings. Original contributions use MIT; preserve third-party licenses.
