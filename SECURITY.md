# Security / 安全反馈

安全问题请通过仓库 Security 页的 **Report a vulnerability** 私密报告。如果该入口不可用，请在 Issue 中请求私密联系方式，不要公开漏洞利用细节、令牌或私人数据。

请提供软件版本、操作系统、最小复现步骤及影响。当前维护范围为最新公开预览版本。

## English

Use **Security → Report a vulnerability** to report security issues privately. If unavailable, request a private contact in an issue without posting exploit details or sensitive data. Include the version, OS, reproduction steps and impact. The latest public preview is the current maintenance target.
