# Changelog / 更新记录

## 0.5.43 — Public preview / 公开预览版

- Minecraft Java 世界浏览、第一人称观察者移动、地图镜头记忆与坐标跳转。
- 本地 Minecraft 材质、可选增强光照、阴影和水面反射。
- 高版本转 1.12.2、可视化方块映射、候选排序和同步镜头对照。
- 可视化裁剪、空白区块清理与全地图方块替换。
- 方块检查器、AI 蓝图、CLI 与待批准/已批准组件库。
- 中英文即时切换、自定义语言文件和持久资源配置。
- MIT 许可证，版权署名：洛神Field。

This public preview includes world browsing and first-person navigation, local Minecraft materials, optional enhanced rendering, 1.12.2 conversion and visual mappings, crop/cleanup/replacement tools, block inspection, blueprints and a component library. English and Chinese are included, with editable language files and persistent preferences. Original code is licensed under MIT by 洛神Field.
