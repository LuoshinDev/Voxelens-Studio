# AI 世界格式

## `.zz`

`.zz` 是 UTF-8 JSON，也是 AI 当前唯一直接生成和修改的项目文件。它描述“建造什么、放在哪里、如何处理冲突”，不描述 MCA sector、NBT 字节或 GPU 网格。

坐标固定为 X 向东、Y 向上、Z 向南；所有范围采用 `min` 与 `maxExclusive`，避免边界歧义。机器可读约束位于 `schemas/zhujie.plan.v1.schema.json`，跨字段约束以 Core 验证器为最终标准。

当前 v1 蓝图可以表达：

- 有语义名称的选择范围；
- 精确方块状态、候选方块与材质 traits；
- 确定性的填充与柱列操作；
- 每次写入的冲突策略；
- 可选的玩家脚部 `spawnPoint`，用于预览跳转并同步到导出世界；
- 基础场景 revision 与编译版本。

蓝图根对象可以携带可选的 `visualProfile`，用来记录预览所需的 Minecraft Java 材质身份：
`edition`、`versionName`、`dataVersion` 与 `storageFamily`。它只决定客户端资源兼容族和贴图/模型选择，
不参与方块事实、坐标、编译哈希或 Minecraft 世界写入；因此 `.zz` 与 `.zjjscene` 的规范场景仍然版本中立。
从世界或 `.schematic` 导出的蓝图会自动保留该提示；未记录此字段时仍可读取，并根据方块状态保守推断兼容族。AI 新建蓝图时若要求
接近实际游戏的预览，应明确填写目标版本，例如 Java 1.20 使用
`{"edition":"java","versionName":"1.20","dataVersion":3463,"storageFamily":"modernSectionPalette"}`。

`spawnPoint` 使用与蓝图相同的整数方块坐标，并表示玩家脚部位置。筑界镜用它启用“跳转到出生点”，从蓝图导出 Minecraft 世界时也优先使用该值；字段缺失的旧蓝图继续采用场景推断位置。标准 AI 新工程固定使用 `{"x":0,"y":32,"z":0}`，首批施工必须先提供 Y=31 的安全落脚面和 Y=32、33 的两格净空。

蓝图禁止嵌入脚本和原始 NBT。编译结果是按 Section 分组、带稳定哈希的 `SceneDelta`，先进入可放弃的预览事务，再由用户决定是否提交。

单份蓝图最多声明 10,000 个操作并尝试写入 16,777,216 个方块；更大的建造必须拆成多个可预览、可审查、可撤销的变更。桌面端在后台编译，并允许窗口关闭时取消，畸形或显式 `null` 的结构只返回验证错误，不得拖死界面。

## `.zjjscene`

`.zjjscene` schema v2 使用单文件 SQLite，并以 WAL 支持可靠事务。它保存版本中立的规范方块状态、稀疏 head、revision Section、变更记录与提交校验；AI 通过摘要和局部切片理解场景，不直接写数据库。

每个 Section 固定 4,096 个体素，Section Y 是有符号整数，因此原生支持负 Y。方块状态是事实源；网格、贴图、LOD、光照和阴影都是可重建缓存。

## Minecraft 适配边界

当前可以把 1.12.2 Legacy Anvil 与 1.13+ Modern Palette 世界只读规范化为统一 Section。现代解析兼容旧式 `Palette` / `BlockStates` 和现代 `block_states` 容器、两种 packed-long 布局、负 Section Y、方块属性、光照与方块实体；畸形 palette index、重复 Section Y 或索引坐标不一致会明确失败，不会静默变成空气。

现代方块可先生成只读的 1.12.2 降级预览。转换器统计精确、替代、可见兜底与阻断映射，计算合法的整体 Y 偏移，并以惰性 Chunk 源供预览和导出使用，不把所有 Chunk 同时复制到内存。

转换导出不覆盖源世界。`Minecraft1122WorldExporter` 按 Chunk 流式写入目标同级的暂存目录，重编码 1.12.2 numeric `ID:data`、光照与方块实体，持续校验来源 revision，完成后才提交为新的世界文件夹；失败或取消会清理暂存结果。主世界、下界、末地、受控附属文件和目标冲突策略均显式处理，`session.lock` 不会复制。地图裁剪、清理与方块替换是独立的原地修改操作。

导出前检查目标高度与映射兼容性。对于不能完整放入 Y=0–255 的世界，需要用户明确确认顶部裁切；用户选择父目录，应用生成新的目标目录并拒绝源世界或其子目录，同时显示进度与最终路径。

## AI 建筑师必须保留的方块状态

方块身份是完整的 `name + properties`，不是只有方块名，更不是只有旧版数字主 ID。AI、蓝图编译器、缓存和 Renderer 都必须使用 `BlockState.CanonicalKey` 作为状态身份；禁止按 `state.Name`、纹理名或旧版主 ID 合并状态。否则同一个旧版 ID 下的花卉会被压成一种草，活板门也会丢失方向、开合和上下半。

`.zz` 只写版本中立的规范状态，不直接写数字 `ID:data`。例如打开且位于上半格、朝东的橡木活板门必须表达为：

```json
{
  "name": "minecraft:oak_trapdoor",
  "properties": {
    "facing": "east",
    "half": "top",
    "open": "true",
    "powered": "true"
  }
}
```

双高植物必须由相邻的两个方块共同组成。AI 放置向日葵时，要在 `(x,y,z)` 写 `minecraft:sunflower[half=lower]`，并在 `(x,y+1,z)` 写 `minecraft:sunflower[half=upper]`；不能把整株植物简化成一个 `grass`，也不能只写下半株。读取 1.12.2 世界时，上半格 metadata 主要表达“这是上半株”，植物品种必须从 `(x,y-1,z)` 的下半格恢复；禁止仅凭上半格低位猜品种。该相邻查询必须能够跨 Section 边界工作。

1.12.2 适配器在支持的规范状态和四位 metadata 之间转换。下表列出蓝图中常见的状态族：

| 1.12.2 编码 | 规范状态含义 | 不可丢失的信息 |
| --- | --- | --- |
| `31:0..2` | 枯灌木、草、蕨 | 植物种类 |
| `38:0..8` | 罂粟、兰花、绒球葱、茜草花、四色郁金香、滨菊 | 花卉种类 |
| `175:0..5` | 向日葵、丁香、双高草、大型蕨、玫瑰丛、牡丹的下半株 | 植物种类与 `half=lower` |
| `175:8..15` | 双高植物的上半株标记 | `half=upper`；植物种类从正下方 `175:0..5` 继承 |
| `96:0..15` | 橡木活板门 | `facing`、`open`、`half`，以及对应的动力状态 |
| `167:0..15` | 铁活板门 | `facing`、`open`、`half` |

楼梯、台阶、门、栅栏门、按钮、拉杆、告示牌、原木轴向、染色方块等也遵循同一规则：凡是规范状态带有属性，AI 不得擅自省略。现代方块降级到 1.12.2 时可以替换材质，但必须优先保留结构轮廓和 `facing` / `axis` / `half` / `type` / `open` 等几何属性，并在不能精确保留时产生映射诊断。

## 1.12.2 降级契约

内置转换器按以下顺序为现代方块选择 1.12.2 替代，并在预览中保留映射原因与 `Exact`、`Similar`、`VisibleFallback`、`Blocked` 质量诊断：

1. 1.12.2 注册表精确状态，以及可编码的流体和 16 色系；
2. 木材、楼梯、台阶等形状与朝向保持；
3. 兼容的旧版状态；
4. 现代形状的显式替代；
5. 现代材质族和颜色相似替代；
6. 根据名称语义选择玻璃、植被、木材、砌体、金属或相近色实体块的确定性兜底；禁止随机颜色和统一萤石兜底。

非空气映射到空气默认非法。唯一例外是 `minecraft:light`：它在现代客户端本来就是不可见的技术性光源，转换时写为空气并保留已有区块光照，避免建筑被大量萤石污染。此例外由映射结果的 `AllowsInvisibleTarget` 明确标记，不能扩展到其他未知方块。

用户覆盖保存在 `%LOCALAPPDATA%\筑界镜\minecraft-1.12.2-block-mappings.json`，格式版本和目标版本都必须通过校验。来源键写完整 `canonical state` 时只覆盖该状态；写裸方块名（如 `minecraft:cherry_stairs`）时覆盖该方块全部状态，并由转换器把 `facing`、`axis`、`half`、`open` 等可兼容属性迁移到所选的 1.12.2 方块族，不能把所有楼梯、门或活板门固定成同一朝向。保存采用同目录临时文件加原子替换，规则 revision 随内容变化，预览缓存和导出必须使用同一规则快照。

若世界高度为 `[minY, maxY]`，1.12.2 整体位移 `d` 必须满足：

```text
max(0, -minY) <= d <= 255 - maxY
```

区间为空时，当前转换预览会阻止无损导出并要求用户调整方案，禁止静默裁切或丢块。导出操作只接受已通过高度与阻断映射检查的预览结果。
